WoW Stick Bridge

Виртуальный геймпад из клавиатуры для WoW Forever: клавиши движения транслируются в левый стик виртуального Xbox 360. Персонаж разворачивается и бежит на полной скорости, как в геймпадном интерфейсе.

Скачать установщик 1.7 Портативная версия GitHub

Windows 10/11 x64 · нужны права администратора (один раз, для драйвера ViGEmBus) · установщик не подписан

Зачем это нужно

В геймпадном режиме WoW Forever левый стик даёт «action-движение»: назад — персонаж разворачивается и бежит на полной скорости, а в режиме клавиатуры+мыши та же клавиша — медленный backpedal. Аддоном это не исправить: движение и поворот — защищённые функции клиента, синтез ввода аддонам запрещён. Поэтому утилита даёт клиенту настоящий виртуальный геймпад — и вы получаете поведение 1:1.

Что умеет

W + A + S + D через стик

По умолчанию все четыре клавиши движения уходят на левый стик; диагонали нормализуются. Клавиши прячутся от игры (swallow), поэтому бинды не конфликтуют.

Пауза для чата — Alt

Короткое нажатие Alt выключает трансляцию: буквы снова печатаются в чате. Ещё одно нажатие — обратно. Ctrl+Alt+S работает так же.

Правило A/D при беге назад

Инверсия A/D, когда персонаж развёрнут, — на лету переключается Ctrl+Alt+X (normal / flip always / flip when S / flip when W).

Диагностика

Лог bridge.log, Ctrl+Alt+D — принудительный стик на 3 секунды, режим --debug. Видно, что именно уходит в игру.

Гибридный режим

Штатный геймпадный драйвер, поэтому рядом работают мышь и клавиатура: камера, способности, макросы — как обычно.

Портативно и без зависимостей

Один exe + DLL. Установщик сам приносит ViGEmBus; для портативной версии есть Install-Driver.cmd.

Как включить

  1. Установи драйвер (установщик делает это сам; в портативной версии — Install-Driver.cmd).
  2. Запусти игру и включи ввод геймпада: /console GamePadEnable 1. Интерфейс можно оставить клавиатура+мышь.
  3. Запусти run.cmd (или ярлык WoW Stick Bridge).
  4. Проверь: W — вперёд, S — разворот и бег, A/D — влево/вправо. Перед чатом — Alt.

Без установщика: распакуй портативный zip → один раз Install-Driver.cmd (админ) → run.cmd.

Горячие клавиши и опции

КлавишиДействие
Alt (коротко)Вкл/выкл трансляцию — пауза для чата
Ctrl+Alt+QВыход
Ctrl+Alt+XПравило A/D: normal → flip always → flip when S → flip when W
Ctrl+Alt+DСтик вниз на 3 секунды (диагностика)
--only-s            только S (без W/A/D)
--no-swallow        не прятать клавиши от игры
--invert            перевернуть вертикаль
--ondemand          пад только на время нажатия
--debug             подробный лог
--process Wow       имена процессов игры
--flip-x normal|always|backward|forward   правило A/D

Требования

Windows 10/11 x64 · .NET Framework 4.8 (в системе уже есть) · права администратора для установки драйвера ViGEmBus · клиент с поддержкой геймпада (WoW Forever).

Исходники и сборка

Исходник — один файл src/WoWStickBridge.cs. Сборка встроенным компилятором Windows: 

build.cmd

Установщик — Inno Setup 6, скрипт installer/setup.iss. Компоненты и лицензии: LICENSES.txt, licenses/.
