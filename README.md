# WoW Stick Bridge

Виртуальный геймпад из клавиатуры для **WoW Forever**: клавиши движения (по умолчанию **W, A, S, D**) транслируются в левый стик виртуального Xbox 360 через драйвер **ViGEmBus**. Клиент видит это как нативный геймпадный ввод — и персонаж **разворачивается и бежит на полной скорости**, а не медленно шагает назад. Плюс Alt-пауза, чтобы писать в чат, и настраиваемое правило A/D.

## Зачем

В WoW Forever в геймпадном интерфейсе левый стик даёт «action-движение»: персонаж поворачивается лицом к направлению движения и бежит на полной скорости. В режиме клавиатуры+мыши та же клавиша «назад» — это медленный backpedal.

Аддоном это не исправить: движение и поворот персонажа — защищённые (secure) функции клиента, а синтез ввода аддонам запрещён. Поэтому единственный способ получить 1:1 — дать клиенту настоящий (виртуальный) геймпад. Этим и занимается WoW Stick Bridge.

## Скачать

Актуальная версия — **[Releases](https://github.com/Follen22/wow-stick-bridge/releases/latest)**:

* **`WoWStickBridge-Setup-1.7.exe`** — установщик: ставит программу в Program Files, сам устанавливает драйвер ViGEmBus (если его нет), создаёт ярлыки, может добавить скрытый автозапуск.
* **`WoWStickBridge-Portable-1.7.zip`** — портативная версия: распаковать, один раз запустить `Install-Driver.cmd`, затем `run.cmd`.

## Установка

### Установщик (рекомендуется)

1. Запусти `WoWStickBridge-Setup-1.7.exe` (нужны права администратора — для драйвера).
2. Установщик сам поставит **ViGEmBus 1.22.0**, если его ещё нет.
3. Ярлыки появятся на рабочем столе и в меню Пуск.
4. Запусти ярлык **WoW Stick Bridge**, включи в игре геймпадный ввод:
   ```
   /console GamePadEnable 1
   ```
5. Играй: **W** — вперёд, **S** — разворот и бег назад, **A/D** — влево/вправо.

Установщик не подписан — SmartScreen может предупредить: «Подробнее → Выполнить всё равно».

### Портативная версия

1. Распакуй zip.
2. Запусти **`Install-Driver.cmd`** один раз (админ — поставит драйвер ViGEmBus).
3. Запусти **`run.cmd`** (или `run.cmd --ondemand`).

Удаление установщика: «Программы и компоненты» → WoW Stick Bridge. Драйвер ViGEmBus при удалении не трогается (может использоваться другими программами).

## Использование

* `run.cmd` — обычный запуск: W+A+S+D через стик, клавиши спрятаны от игры (swallow).
* `run-swallow.cmd` / `run-debug.cmd` — то же + подробный лог `bridge.log`.
* `run-wasd.cmd` — явный вариант «всё движение через стик».
* `run-ondemand.cmd` — виртуальный пад создаётся только пока клавиша зажата.

Горячие клавиши (работают в игре):

* **Alt** (короткое нажатие без других клавиш) — пауза: буквы снова печатаются в чате; ещё раз — включить обратно.
* **Ctrl+Alt+Q** — выход.
* **Ctrl+Alt+X** — правило A/D: `normal → flip always → flip when S → flip when W`.
* **Ctrl+Alt+D** — принудительный стик вниз на 3 секунды (диагностика).

Дополнительные опции:

```
--only-s            только S (без W/A/D)
--no-swallow        не прятать клавиши от игры (тогда отвяжи бинды в настройках управления)
--invert            если вертикаль перевёрнута
--no-alt-toggle     отключить паузу по Alt
--ondemand          создавать пад только на время нажатия
--debug             писать каждый тик в bridge.log
--process Wow       имена процессов игры
--flip-x <mode>     правило A/D: normal|always|backward|forward
```

Лог: рядом с exe, а если папка недоступна (Program Files) — `%LOCALAPPDATA%\WoW Stick Bridge\bridge.log`.

## Требования

* Windows 10/11 **x64**.
* .NET Framework 4.8 (в Windows 10/11 уже установлен; установщик проверит).
* Права администратора — один раз, для установки драйвера ViGEmBus.
* Клиент с поддержкой геймпада (WoW Forever). Для других игр утилита тоже будет работать как обычный виртуальный Xbox-пад.

## Как это устроено

Утилита ловит клавиши глобальным хуком и отправляет состояние виртуальному Xbox 360 (ViGEmBus). В WoW Forever включённый геймпадный ввод обрабатывает это как левый стик: клиент разворачивает персонажа на направление движения и включает полный бег. Обратная связь: `bridge.log`, диагностические горячие клавиши.

Дополнительно: A/D инвертируются при беге назад по правилу `flip when S`, чтобы сохранить привычное управление (правило переключается Ctrl+Alt+X).

## Сборка из исходников

Нужен только встроенный в Windows компилятор (никакого .NET SDK):

```
build.cmd
```

или вручную:

```
%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe /nologo /target:exe /platform:x64 /optimize+ /out:WoWStickBridge.exe WoWStickBridge.cs
```

Установщик собирается Inno Setup 6: `installer\setup.iss` (см. `installer\README.md`).
